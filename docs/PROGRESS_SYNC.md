# 播放进度同步（0.4.0）

## 已确认的协议证据

2026-09-13 使用本应用受 Windows DPAPI 保护的登录态验证：

- `POST /v1/playback-progress/list`，请求 `{"eids":["<episode-id>"]}`，响应 `{"data":[{"eid":"...","pid":"...","progress":2215,"playedAt":"<RFC3339>"}]}`。
- iPhone 暂停截图为 36:55，云端读取为 2215 秒，位置误差为零。
- Windows 0.3.0 实际保存位置为 2233.610491 秒。测试工具上传整数 2233 秒，并保留原始暂停时间。
- `POST /v1/playback-progress/update` 请求 `{"data":[{"eid":"...","pid":"...","progress":2233,"playedAt":"<original-event-time>"}]}`。
- 单独使用原有 User-Agent 和认证头回写，返回 HTTP 400、`Missing client time`。增加当前 RFC3339 格式的 `Local-Time` 与 `Timezone: Asia/Shanghai` 后返回 HTTP 200；回读位置和时间均匹配。
- 用户确认 iPhone 重新打开该集后从回写位置继续播放。

这是一次真实账号的手动协议验证，证明双向数据通路可用；不等同于应用内自动同步验收。不要保存账号 ID、令牌、分享链接查询参数或真实账号原始响应到仓库。

## 实现边界

使用小宇宙非官方接口，认证仍由现有会话管理器负责，凭据不传前端。已有本地播放历史保留；旧记录不能在升级时批量上传。同步的内容只有单集位置和播放发生时间，不创建收听统计、评论或播放队列。

位置允许倒退或归零，不使用“取最大进度”合并。错误不能伪装成空记录。程序加载、恢复定位和切换音源不能生成新的零进度上传。退出先保存本地；云端处理有时间上限，失败留待恢复连接处理。

## 自动同步实现

- `progress.prepare` 在普通播放和恢复前读取云端；3 秒超时使用本地位置并显示同步状态。显式定位优先。
- `progress.save` 继续每 5 秒本地保存，`urgent` 表示暂停、定位、切集或结束，立即唤醒上传任务。普通后台检查间隔 15 秒。
- `progress-sync` 行原子保存本地进度、云端基线、待上传快照及修订号；旧 `progress` 行保留兼容投影。初始化不把旧历史转成上传任务。
- 上传前重新查询云端；查询期间发生的本地保存会使该次上传资格失效。回执只确认自己的修订，失败结果不确定时先回读。
- 两端都变化且事件时间相差不超过 5 秒，或时间明显超前时，暂停等待“继续本机位置／使用云端位置”选择。后端不使用最大位置合并。
- 设置缺省启用。关闭期间的播放仅保存本地，清除对应旧待上传任务；重新开启后按云端位置恢复，不补传关闭期间的记录。
- 网络失败指数退避，限流遵循 `RetryAfter`；退避计时是进程内状态，待上传记录持久化。手动重试会重新尝试，底层平台限流仍生效。
- `progress.status`、`progress.retry`、`progress.choose` 提供状态与恢复操作；`progress.flush` 为正常退出提供最多 2 秒云端处理窗口。

最近同步成功时间表示本进程的成功操作，不跨重启保存。平台没有提供跨设备原子比较更新接口，本地修订检查不能消除“云端读取后另一个设备立即写入”的竞态，因此不承诺同时播放时实时一致。

## 只读协议回归

先在 Starling 登录，再在 PowerShell 运行（只查询，不刷新或写入凭据）：

```powershell
$env:STARLING_LIVE_PROGRESS = '1'
$env:STARLING_LIVE_PROGRESS_EID = '<测试单集 ID>'
go test ./internal/provider -run '^TestLiveProgressReadOnly$' -count=1 -v
Remove-Item Env:STARLING_LIVE_PROGRESS
Remove-Item Env:STARLING_LIVE_PROGRESS_EID
```

普通测试默认跳过真实账号访问。该检查仅记录条数、位置和时间是否有效，不记录单集或账号标识。

## 应用自动同步发布门槛

使用相同账号的 iPhone 和 Windows 候选构建，完成以下测试：

| 场景 | 记录 | 通过标准 |
| --- | --- | --- |
| iPhone → Windows，重复 3 次 | 手机暂停时间、位置；电脑续播时间、位置 | 正常联网，30 秒内可同步，误差不超过 5 秒 |
| Windows → iPhone，重复 3 次 | 电脑暂停时间、位置；手机续播时间、位置 | 同上 |
| 倒回重听、从头播放 | 操作位置及另一端续播位置 | 采用新操作，不能强制恢复较大秒数 |
| 离线后两端分别播放 | 离线本地与云端记录、恢复后的决定 | 保留新进度，无法排序时提供选择 |
| 切账号、关闭同步 | 旧任务与旧响应结果 | 不跨账号保存、不继续发起关闭后的写操作 |
| 暂停、快速切集、退出重开 | 本地保存与待同步状态 | 不上传临时零进度，不因退出丢失已保存任务 |
