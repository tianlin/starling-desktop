# 实现架构与设计变更

## 1. 边界

Windows 宿主只负责窗口、原生消息、允许列表桥和文件对话框。`internal/app` 负责业务编排，`provider` 隔离平台协议，`session` 单独管理凭据与生命周期，`store` 负责按命名空间持久化。前端不直接访问平台认证 API，不持久化令牌。

生产链路：TypeScript UI → Wails `App.Call` → Go 业务服务 → 固定平台域名；音频由唯一 audio 元素直接播放获准的 CDN URL。没有回环账号服务器。演示链路是独立的 `cmd/demo`，用合成 Provider 替代平台，并把固定测试媒体替换为本地 WAV；桌面入口不引用它。

## 2. 相对 PRD 的明确调整

**React 改为原生 DOM TypeScript。** 当前需求没有必须依赖 React 的组件。本次使用严格 TypeScript、明确的页面生命周期和唯一播放器控制器，减少了运行时依赖，并使前端可在当前离线环境真实构建。不是仅提供静态原型；代码实际调用 Go 业务桥。后续需要组件框架时，可保留 `api.ts` / `player.ts` 和业务接口迁移。

**SQLite 使用系统库薄绑定。** 不引入尚无法下载和验证的第三方 Go SQLite 包。Windows 用系统 winsqlite3.dll，Linux 自动化测试用系统 libsqlite3。Windows 不要求 CGo；Linux 测试需要 CGo。两种实现的原生调用路径不同，因此 Linux 测试不能替代 Windows 数据库测试。

**桌面宿主为独立 Go 子模块。** 根模块仅依赖本地二维码编码库，可独立测试会话、安全、分页和存储。`desktop/` 单独依赖 Wails。根目录 `go test ./...` 不会隐式覆盖该子模块；构建脚本分别检查两者。依赖校验使用临时双模块 workspace，不将本地 replace 当作下载模块校验。

**首版使用便携程序与当前用户安装脚本。** 尚无 NSIS 安装包、签名、自动更新。托盘暂用系统回退图标，窗口图标由构建资源提供。Mac / Linux 桌面不在本次实现范围内。

## 3. 认证与 epoch

账号接入默认关闭。一次认证需要短信登录返回完整凭据和身份，再独立调用个人资料接口比较用户 ID。任何不匹配都不建立会话。用户级 DPAPI 保存失败时不降级明文。

每次开始认证、退出或重置都会改变 epoch。网络响应在提交前与原 epoch 比较。写盘回调与退出持有同一个会话锁，避免“检查通过后再被退出”的 TOCTOU。恢复凭据在读取之前捕获 epoch，防止迟到的磁盘读取在退出后重新登录。

401 后所有并发调用共享一个刷新任务。刷新成功时先原子保存轮换后的凭据，再更新内存；原请求最多重放一次。刷新重放前再次检查原 epoch，不切换到另一个账号的凭据。网络失败保留现有身份，永久认证失败标记需要重新连接。

## 4. 列表一致性

游标不由前端构造，统一作为规范 JSON 的 base64url 透传。循环游标、异常空页、互相矛盾的结束标志会停止加载。通用解析器缺少结束字段时显示“未确认完整性”；收藏/订阅适配器依据 2026-09-12 实测，将有效 data 数组且同时省略 loadMoreKey/hasMore 的响应作为末页。此规则不扩散到未验证端点。内存缓存部分结果，SQLite 仅保存本轮加载结束的结果；不会从不完整页推断删除。完整内存视图和磁盘缓存都按 10 分钟判断过期。

平台 API 使用每个 Client 生命周期内稳定的随机 UUID 头，不读硬件、不持久化、不伪装手机。收藏接口缺失此头会返回 400 / rpc_error；User-Agent 仍为 Starling。列表返回可用缓存时的嵌套错误也进入脱敏诊断，避免 ok=true 掩盖刷新失败。

同时加载限制为每个列表一个请求；平台网络并发上限 3。安全上限为单次响应 12 MiB、每轮 1,000 页 / 20,000 条，列表单行数据写盘上限 16 MiB。UI 对云端长列表按每屏 60 条显示，筛选仅作用于已加载内容。取消请求与后续加载有顺序屏障，防止旧取消覆盖新刷新。

这些是保护阈值，不是平台 API 配额的已知事实。游标遍历不提供平台级事务快照；手机端同期增删可能影响集合，需要稳定窗口下核对。

## 5. 播放与持久化

`Player` 长期持有同一个 HTMLAudioElement，路由不创建第二播放器。每次播放生成 requestId 和本地序号；Go 取消前一解析，前端也丢弃晚到响应。暂停会撤销待播放意图；暂停后晚到的媒体错误不能自动触发重播。

进度按 timeupdate 节流到约 5 秒，并在暂停、切换、正常退出时保存。所有保存都携带捕获的账号 epoch，并通过串行保存链避免旧位置覆盖新位置。只有 ended 事件标记听完，不按接近结尾猜测。恢复时保持暂停，等待媒体实际可寻址后再应用已保存位置。

正常退出采用前端落盘确认；无响应的渲染器最多等待一个有限宽限期，再退出并依赖上次成功检查点。强退、断电或写盘失败仍可能丢失最后一段进度，不能宣称零损失。

## 6. 原生与内容安全

Win32 辅助窗口接收托盘、热键和电源消息。原生媒体键注册失败会反映为能力不可用；不能据交叉编译宣称键盘 / WebView2 组合不会双触发。睡眠 / 恢复和设备移除采取保守暂停策略。

Wails 资源带 CSP。说明内容仅允许重新构造的基本文本节点，不执行原 HTML；外部 HTTPS 链接必须经宿主验证后才交给默认浏览器。与媒体、图像有关的兼容性扩展应先核实域名，不得使用关闭 Web 安全的开关。
