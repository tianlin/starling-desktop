## PRD 12.1 量化验收

以下保持 PRD 原定目标，不是已测结果。基线为 Windows 11 x64、8 GB 内存、SSD、正常运行时、稳定网络；记录 CPU、系统及 WebView2 版本、实际带宽和上游延迟。网络异常单独归因但不得从结果中隐去。

- [ ] 5 名受邀测试者均能完成登录、找到收藏单集、开始播放；记录耗时和失败原因，不据此推断总体成功率。
- [ ] 30 次冷启动，主界面可交互 p95 ≤ 3 秒；运行时安装耗时单独报告。
- [ ] 50 次合法可播放样本，点击至实际出声 p95 ≤ 3 秒，缓冲失败单列；静音合成测试不能证明出声指标。
- [ ] 500 条列表场景，统计应用及 WebView 子进程，稳态工作集目标 ≤ 300 MB；超出时评审优化或预算，不直接宣称通过。
- [ ] 正常持久化后的续播误差 ≤ 5 秒；强退/掉电以最后成功检查点单列。
- [ ] 多页列表完整性按 G2 手机同期对照验收；持续收听按 G3 的 3 轮各 4 小时验收。
- [ ] 发布包、数据库及诊断中无明文凭据，账号间无越权读写，关键安全用例全部通过；使用获准隔离账号和脱敏证据。

记录模板：场景、账号类型（不写账号标识）、OS / WebView2 版本、步骤、预期、实际、脱敏证据、结论、提交 SHA、执行日期。任何失败都阻止对应门槛通过。
