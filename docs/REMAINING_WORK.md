# 已知限制与后续验证

更新：2026-09-12，适用于 0.2.0。已通过的自动化和真实只读证据集中在 [TEST_REPORT.md](TEST_REPORT.md)，本页只维护实际限制与未完成事项。

## 接口和账号

- 账号接入默认关闭，私有接口可能变化或拒绝访问。小宇宙 App 扫码已实现；短信路径缺少当前网页的人机验证参数，发送兼容性有限。继续验证不同账号的扫码、自然过期续期、轮换保存、403/429/断网及取消/重开，不强制失效用户凭据。
- 个人库需在稳定集合下与手机同期核对两页以上及大集合；当前真实样本不证明所有账号完整无缺。公开节目页可能只提供预览；更新只缓存近期最多 200 条，不表示完整历史。
- 评论最新采用服务器 TIME 顺序；另一真实样本严格时间降序探针失败，需进一步核对服务器契约与检查预期。REMOVED 无正文引用已修复，复杂线程、审核、关闭评论及禁止回复仍需更多真实样本。
- 真实评论、楼中楼回复和订阅写入需用户在界面主动填写/点击后核对平台结果，自动测试不执行。未知写入结果不得自动重发；取消等待不能撤销已接收的评论。
- 两个账号与访客切换、退出清理及恢复身份仍需完整实机流程；合成隔离用例不代替多账号验证。

## 分发与安全边界

程序当前未签名，没有自动更新或应用商店分发。发布物应绑定提交、CI、版本资源、实际 EXE 哈希、漏洞扫描和依赖材料；后续修改不能沿用旧候选扫描结论。

系统 SQLite、WebView2 和编解码运行时依赖系统更新。用户级 DPAPI 不隔离同用户恶意进程，数据库元数据未整体加密，WebView 缓存只尽力清理，不承诺取证级擦除。需继续开展发布包、诊断和多账号隐私核查；没有外部安全审计结论。

项目非官方，测试和开源许可证不表示获得平台、商标或内容授权。依赖 SBOM 与许可证文本已有生成入口，适用性和系统运行时条款仍需负责人核对；不能以材料收集替代专业结论。

新增验证按测试报告的记录模板保存环境、结果、失败原因、日期、提交和候选哈希。后续验证清单不影响如实描述已经基本可用的功能，也不把尚未执行的场景写成通过。
