# Starling 产品范围与交互原则

版本：0.3.0。目标平台：Windows 11 x64、macOS 14+ arm64/amd64（候选支持，待实机验收）。Starling 是非官方小宇宙桌面客户端，让用户在电脑上找到个人库内容并持续收听。技术实现见 [架构](ARCHITECTURE.md)，实际验证见 [测试报告](TEST_REPORT.md)，尚未完成的验证见 [后续工作](REMAINING_WORK.md)。

## 当前范围

| 能力 | 产品约定 |
| --- | --- |
| 账号接入 | 默认关闭，由用户主动启用；小宇宙 App 扫码、听众身份核对、续期、可选本机保存与退出。短信路径保留但兼容性有限 |
| 个人库 | 订阅节目与收藏单集是两个独立对象；分页、去重、筛选已加载内容、可取消的加载全部、完整缓存 |
| 订阅更新 | 更新单集按日期分组，播放或加入稍后听；近期缓存不等同于完整历史 |
| 探索 | 节目、单集、用户搜索；推荐词、本机搜索历史、创作者作品；主动订阅与不确定结果核对 |
| 公开内容 | 完整节目/单集链接、元数据、清洗后的说明和时间点；公开页预览不伪装完整节目库 |
| 评论 | 登录后阅读热门 / 最新、分页和展开回复，主动发表纯文字评论、回复一级或楼中楼对象；未知关系保持只读 |
| 连续收听 | 单一播放器、播放暂停、定位、倍速、音量、本机队列、书签和断点续播；重启保持暂停 |
| 桌面和数据 | Windows 保留托盘与媒体键；macOS 提供菜单栏及隐藏/退出区分，全局媒体键暂不提供。两平台有睡眠暂停、本地数据清理和脱敏诊断导出 |

本地书签、稍后听和收听进度只属于此设备，不宣称与手机同步。云端收藏仍为只读；没有评论点赞/删除、图片评论、离线下载、付费解锁、转写、自建账号云端、自动更新或 Linux 桌面支持承诺。

## 交互原则

1. 页面切换保持唯一播放器。快速切歌、暂停、退出或切换账号后，迟到结果不能恢复旧音频或污染当前页面。
2. 个人库明确区分未登录、加载、真实空列表、失败、缓存、部分结果和本轮加载结束。缓存过期或刷新失败可展示已有内容，但要说明来源。
3. 只有适配器确认分页结束才标记完整；循环游标、未知结束和安全阈值停止均说明限制。平台没有事务快照，不保证手机同期增删期间的瞬时全量一致。
4. 更新页只对已加载内容排序；评论“最新”使用服务器 TIME 顺序，不承诺跨样本严格按时间降序。删除的引用保留可解释占位，不使整页失败。
5. 登录、发送验证码、评论、回复和订阅均来自用户主动操作。写入结果未确认时保留草稿或待核对状态，不自动重发；取消等待不表示撤销平台已接收的操作。
6. 自然播放结束才自动播放队列下一项；暂停不会因迟到错误重新开始播放。不可定位媒体显示限制，保留旧续播点直至实际恢复或自然播放追平。
7. 支持键盘操作，输入框内的空格不被播放快捷键劫持，弹窗有名称、焦点循环和关闭后焦点返回。DPI、屏幕阅读器和实体媒体键需分别实测。
8. 平台拒绝访问时解释错误并停止无效重试，不绕过访问控制。公开链接访客模式与账号个人库明确区分。

## 数据和工程约束

凭据只在 Go 层使用，选择保存时 Windows 使用当前用户 DPAPI、macOS 使用本机钥匙串，不降级明文。数据库保存本机元数据及状态，账号与访客隔离；评论和草稿仅在内存中。退出账号清理本机对应数据，但不宣称撤销平台令牌或删除已发表评论。详见 [隐私说明](../PRIVACY.md)。

版本号表示软件交付版本，不表示平台官方认可、签名或完整实机安全验收。自动化、真实只读、原生交互及长期稳定性按各自证据报告；未验证事项集中维护，避免多份清单重复过期状态。
