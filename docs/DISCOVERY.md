# 探索新播客

在左侧「探索」搜索节目、单集和主播/用户，查看创作者作品并订阅节目。账号接入默认关闭，主动启用并连接账号后读取平台内容。

## 使用

- 输入关键词后按 Enter 或点击搜索；中文输入法选词时的 Enter 不触发搜索。
- 「节目」「单集」「主播 / 用户」分别读取平台对应搜索结果。搜索历史最多 10 条，最近使用在前，可单条删除或清空；「你可能想搜」来自平台接口。
- 点击用户查看资料及其创作节目。普通听友可以没有创作节目；不根据昵称推测主播身份。
- 节目卡片和详情提供同一订阅状态。单集可直接播放、加入稍后听或查看详情。返回探索保留结果、分类和滚动位置，不中断当前播放。
- 访客可输入搜索词，提交后引导连接账号，连接成功继续搜索。完整小宇宙链接沿用原来的打开链接功能。

## 订阅与数据

仅提供新增订阅，不提供取消订阅或关注用户。「已订阅」表示平台已确认；缺少状态时显示未知，不依据不完整的个人库推断未订阅。

每次明确点击只发送一次订阅请求。结果不确定时先读回状态；仍不确定则显示「结果待确认」，可「核对状态」，再由用户明确允许重新订阅。不会因为超时或令牌续期自动重发写请求。

确认成功后保留独立的订阅记录，刷新个人订阅与更新。旧分页不能抹去刚确认的节目；刷新失败时保留原缓存和已确认记录。本机保存失败不把平台成功变成订阅失败，界面保留确认状态并提示缓存问题。普通“已订阅”状态读取不会触发更新页刷新。

搜索结果只缓存在内存；搜索历史和确认记录存入现有 SQLite，按账号隔离。退出账号沿用现有私有数据删除规则。搜索词、响应内容和凭据不写入诊断日志。

搜索接口在正常终页省略下一页游标及 hasMore；三类搜索已完整翻页核验这一行为。成功返回有效数组且省略这两个字段时，显示「已显示本次搜索的全部结果」，零条则显示没有相关内容。异常响应和分页冲突仍提示失败，不按正常结束处理；此规则不扩展到其他接口。

## 验证边界

真实只读检查已覆盖推荐词、三类搜索分页及终页、创作者有作品/无作品和订阅状态，未发送真实订阅请求或刷新/写回凭据。协议与样本见 [接口契约](DISCOVERY_API.md)，汇总结果见 [测试报告](TEST_REPORT.md)。

`tests/e2e/discovery.py` 使用界面、Go 业务层和合成提供方验证操作链路，不连接真实账号。真实订阅写入、读回及 Windows 原生界面仍需通过用户主动订阅验收。

```powershell
# 合成回归，使用已安装 Playwright 的 Python 解释器
python tests/e2e/discovery.py

# 仅在主动进行真实只读检查时启用
$env:STARLING_LIVE_DISCOVERY = '1'
try { go test ./internal/provider -run '^TestLiveDiscoveryReadOnly$' -v -count=1 }
finally { Remove-Item Env:STARLING_LIVE_DISCOVERY }
```

默认测试和 CI 跳过真实账号检查。合成浏览器测试已加入 CI。
